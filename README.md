# ChatApp Part 2 and 3

## Description - A chat application developed for PROG5121 POE part 2 using java.

This includes
-User registration
-User login
-Message send
-Validating message
-Generating a message hash
-Store message in JSON
-JUnit tests
-Github Actions being added and used

## How to run the project
1. Open ChatApp in netbeans
2. Check maven dependencies
3. Run the MainApp class
4. Input details based on the prompt

## Running the tests
1. Open MessageTest
2. Right click on the project
3. Test file
4. All tests should pass successfully

## GitHub Actions CI
The project make use of this to run the unit tests automatically on every push
